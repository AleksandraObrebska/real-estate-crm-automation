Sales Automation Deployment (Real Estate) & CRM Architecture
Technical Objective
To build a flawless, budget-friendly data flow architecture (ManyChat -> MailerLite) aimed at plugging leaks in the sales pipeline for the final 4 premium houses, and to deliver a comprehensive technical blueprint for a future HubSpot CRM migration.
Implemented System Configurations (Current State - MVP)

1. Process Architecture & Data Hygiene
Designed a structured real estate Sales Pipeline with clear transition criteria between Deal Stages: from the initial inquiry, through property presentation, to the reservation contract.
Conducted a technical audit of the website, detecting and resolving a critical contact form bug that was previously causing premium lead leakage.
Implemented strict database segmentation rules using Custom Tags to distinguish between individual buyers (families) and high-yield premium investors.

2. Integrations & Workflow Logic (Automation)
Configured an automated user qualification pathway in ManyChat based on behavioral triggers and budget filters.
Designed automated lead magnet delivery workflows and email sequences (Day 1, 3, 7) in MailerLite, triggered automatically upon contact capture by the bot.
Coordinated and streamlined data flows across traffic generation channels (Meta Ads), automation tools (ManyChat/MailerLite), and the onshore sales team.
Target System Rules in HubSpot CRM (Future-Proof Recommendation)
As part of preparing the client for operational scaling, I mapped out a comprehensive process blueprint in Miro for a target HubSpot deployment:
Advanced Workflows: Automated Task creation for sales agents and an automatic webhook call to the legal team triggered instantly when a deal is moved to the "Reservation" stage.
SLA & Alerting: Automated escalation alerts sent to management if a premium lead remains stagnant at the presentation stage for more than 5 days.
Dashboards: Configuration of analytical reporting dashboards to track real-time pipeline conversion rates, agent response times (Time-to-Respond), and exact return on investment (ROI) from Meta Ads and property listing portals.

Tools used: HubSpot CRM (Blueprint), MailerLite, ManyChat, Meta Ads, Miro, API/Integrations
